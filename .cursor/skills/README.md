# Skills Refugio Data

Skills por experto para guiar el desarrollo según la arquitectura, diseño, estilos y buenas prácticas del proyecto.

## Skills disponibles

| Skill | Área | Cuándo usar |
|-------|------|-------------|
| **backend-refugio** | API FastAPI | Routers, servicios, modelos, schemas, auth, integraciones |
| **frontend-refugio** | SPA React + Vite | Componentes, páginas, rutas, servicios, AuthContext |
| **mobile-refugio** | Apps Expo | Kiosk, runner, packages compartidos |
| **infra-refugio** | Docker, Nginx | docker-compose, Dockerfiles, despliegue VPS |
| **data-refugio** | Capa de datos | Big Query, PostgreSQL, Power BI, GDrive, FileStore |
| **delivery-refugio** | Módulo Delivery | API delivery, kiosk, runner, WebSocket, matching |
| **ui-ux-refugio** | Diseño y estilos | Componentes, variables CSS, Tailwind, paleta |

## Reglas globales (AGENTS.md)

- Sin hardcodeos; usar constantes
- Arquitectura limpia, modular y escalable
- Manejo de excepciones modular
- Documentación en README.md por commit
- Respetar arquitectura, diseño y estilos del sistema
